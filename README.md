# STARFALL — плейтест-сборка

Публичная браузерная сборка игры для тестирования друзьями.

- Играть: https://fewvar.github.io/starfall-playtest/
- Версия: этап E.4
- Исходный коммит приватного репозитория: `41a6a72`

В E.4 основная линейка расширена до десяти боссов. Заросли получили
Корнеразум, Кислотное облако — Ядро Коррозии, Диссонанс — Ложный Маяк.
У каждого босса три фазы с честными телеграфами опасных атак.

В сборке также есть физический и технический урон, RAM, сопротивления,
постоянный бестиарий на `Esc` и зацикленная фоновая композиция. Звук целиком
включается и выключается клавишей `N`.

Исправление `00679d0`: `Esc` открывает полное меню с картой,
характеристиками, бестиарием и добровольным выходом из забега. При выходе
обломки и статистика сохраняются.

В этот репозиторий входят только файлы, необходимые для запуска игры в браузере. Внутренние заметки, планы и материалы разработки здесь не публикуются.
